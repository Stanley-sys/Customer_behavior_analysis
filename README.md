## Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI. The goal of the project is to analyze raw data, clean and transform it, perform exploratory data analysis (EDA), execute SQL-based insights, and create an interactive dashboard for business reporting.

The project highlights skills in data cleaning, analysis, database querying, and visualization — making it suitable for showcasing practical analytics abilities to recruiters and hiring managers.

---

## Dataset

The dataset used in this project is **Customer Shopping Behavior Data**, which contains customer purchase patterns, shopping preferences, and transaction details.

### Dataset Information

* **Total Records:** 3,900 rows
* **Total Columns:** 18 features
* **Data Type:** Structured CSV dataset

### Key Columns

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount (USD)
* Location
* Size
* Color
* Season
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Promo Code Used
* Previous Purchases
* Payment Method
* Frequency of Purchases

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Customer_behavior_analysis.git
```

### 2. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 3. Run Python Analysis

Open the Jupyter Notebook or Python script and execute the analysis workflow.

```bash
jupyter notebook
```

### 4. Run SQL Queries

Execute the SQL scripts in:

* PostgreSQL
* MySQL
* SQL Server

using your preferred database management tool.

### 5. Open Power BI Dashboard

Open the `.pbix` file in Power BI Desktop to explore the dashboard.
